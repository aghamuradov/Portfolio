# Portfolio – Sakhavat Aghamuradov

Persönliche Portfolio-Website (Deutsch), veröffentlicht über GitHub Pages:
https://aghamuradov.github.io/Portfolio/

- Statische Seite ohne Build-Schritt: `index.html`, `style.css`, `script.js`
- Titelbild: eigenes Foto aus der Deichman-Bibliothek in Oslo (`assets/img/`)
- Oslo-Silhouetten (Opernhaus, Barcode, Deichman, MUNCH) als eigene SVG-Illustration
- Dokumente (Lebenslauf, Arbeitszeugnisse, Notenspiegel) unter `assets/docs/` – persönliche Daten geschwärzt
- Hell-/Dunkelmodus, responsiv, PDF-Vorschau im Browser

Lokal ansehen: `python3 -m http.server` im Projektordner starten und http://localhost:8000 öffnen.
